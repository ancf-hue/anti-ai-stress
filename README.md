Модуль	Что делает

🎮 Игры для разрядки

📊 Статистика	График настроения за неделю / месяц. Счётчик использованных техник и игр. Триггеры (что чаще всего вызывает гнев).

📱 PWA	Установка на главный экран телефона как нативного приложения. Работает без сети после первого визита.
